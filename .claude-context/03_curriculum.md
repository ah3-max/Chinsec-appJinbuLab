# 03_curriculum.md — 課程設計 v2

> 此檔記錄完整的課程架構：7 個等級 × 12 個情境 = 84 個關卡的設計大綱。
> 設計新關卡內容、改寫題目時必讀。

---

## 🎯 課程設計核心原則

1. **線性升級**：必須從 Level 0 開始，前一級 Boss 通關才解鎖下一級
2. **養老院聚焦**：所有 12 情境都在養老院實務中發生
3. **能力導向**：學員學完不只是「認字」，而是「能做事」
4. **漸進式介面**：母語為主 → 雙語對照 → 中文沉浸
5. **情境疊加**：同一情境（如「餵食」）會在 L1-L4 用不同深度重複出現

---

## 📊 課程整體結構

```
Level 0: 注音預備班 (Pre-A1)
         └─ 4 階段 + Boss 通關
         
Level 1-6 (A1 → C2)
         ├─ 主軸語言課 (詞彙/語法/發音)
         ├─ 12 個養老院情境關卡
         └─ Boss 通關考試 (聽/說/讀/寫四項)
                ↓
         📜 內部認證證書
                ↓
         💰 績效獎金事件觸發
```

## 🎓 Level 0：注音預備班

**對標**：Pre-A1
**詞彙量**：37 注音符號 + 4 聲調
**估時**：20 學時
**介面**：純母語

### 8 階段
| Z# | 標題 | 內容 | 關鍵練習 |
|---|---|---|---|
| Z1 | 韻母基礎 | ㄚㄛㄜㄝ | 聽音選符號 |
| Z2 | 介符與複韻母 | ㄧㄨㄩ + ㄞㄟㄠㄡ | 辨音、聽寫 |
| Z3 | 聲隨韻母 + 捲舌韻母 | ㄢㄣㄤㄥㄦ | 前/後鼻音對比 |
| Z4 | 聲符基礎 | ㄅㄆㄇㄈㄉㄊㄋㄌ | 送氣/不送氣對比 |
| Z5 | 聲符進階 | ㄍㄎㄏㄐㄑㄒ | 三拼練習 |
| Z6 | 聲符高階 | ㄓㄔㄕㄖㄗㄘㄙ | 翹舌/平舌對比（最難） |
| Z7 | 聲調系統 | 一二三四聲 + 輕聲 | 媽麻馬罵對比 |
| Z8 | 結合韻完整應用 | 22 個結合韻 | 拼讀完整音節 |

### Z9（Boss 通關）
- 50 題綜合測驗（聽 30、寫 20）
- 通過 80% → 解鎖 Level 1

## 🎓 Level 1：A1 入門級

**對標**：CEFR A1 / TOCFL Level 1
**詞彙量**：累計 300 字
**估時**：60 學時
**介面**：母語為主（85% 母語 / 15% 中文）
**主題定位**：剛到台灣的新人，認識阿公阿嬤、學會基本求生用語

### Level 1 Boss 通關考試
- **聽力**：20 題，含對話、語句辨識
- **口說**：5 題情境問答（AI 評分）
- **閱讀**：15 題，含詞彙、簡單句子
- **寫作**：手寫 10 個關鍵字 + 抄寫 3 個句子
- **通過標準**：四項皆 ≥ 70%，總分 ≥ 75%
- **獎勵**：證書（PDF）+ NT$ 1,500 一次性 + +500/月

## 🎬 情境關卡的標準結構

每個 L?-S?? 情境關卡內含 **5 個學習階段**：

### 第 1 階段：情境引入（Story Hook）
- 短動畫或漫畫式對話
- 真實照服員會遇到的場景
- 用學員母語說明情境

### 第 2 階段：核心詞彙學習
- 8-15 個新詞彙
- 每個詞彙：漢字 + 注音 + 拼音 + 母語翻譯 + 音檔 + 例句
- SRS 排程：學完後 1 天、3 天、7 天複習

### 第 3 階段：句型練習
- 3-5 個關鍵句型
- 句型範例 + 替換練習
- 互動題目：拖曳、填空、排列

### 第 4 階段：情境對話
- AI 角色扮演（學員扮照服員，AI 扮阿公/家屬/同事）
- 5-10 輪對話
- 即時反饋發音、用詞

### 第 5 階段：應用測驗
- 8-10 題綜合（聽 / 說 / 讀 / 寫）
- 通過 70% → 解鎖下一情境
- 不通過：自動補充練習

## 🏆 能力指標系統（Competency）

### 為何要有 Competency？
不只記「學了哪課」，而是**「會做什麼事」**——這對績效獎金的客觀性至關重要。

### Competency 編碼規則
```
COM-XXX：依新增順序編號（永久不變）
分類前綴：
  GREET-  問候類
  CARE-   照護動作類
  COMM-   溝通類
  EMER-   緊急處理類
  ADMIN-  行政管理類
```

### 技術實作
```typescript
// src/lib/ui-language.ts
export function getUiLanguageMode(userLevel: Level): 'native' | 'native_first' | 'bilingual' | 'immersion' {
  switch (userLevel) {
    case 'ZHUYIN':         return 'native';
    case 'A1_BEGINNER':    return 'native_first';
    case 'A2_BASIC':
    case 'B1_INTERMEDIATE': return 'bilingual';
    case 'B2_UPPER_INTER':
    case 'C1_ADVANCED':
    case 'C2_PROFICIENT':   return 'immersion';
  }
}
```

// 元件範例
<TranslatedText
  hanzi="阿公早安"
  mode={getUiLanguageMode(user.currentLevel)}
  nativeLang={user.nativeLanguage}
/>

// 'native_first' → "อรุณสวัสดิ์คุณปู่ — 阿公早安"
// 'bilingual' → "阿公早安 / อรุณสวัสดิ์คุณปู่"
// 'immersion' → "阿公早安" (hover 才顯示母語)

## 🧪 入學能力測驗（Placement Test）

新員工註冊時做 10-15 題快速測驗，自動分配起始等級：

### 測驗結構
| 題目類型 | 題數 | 用途 |
|---|---|---|
| 注音認音 | 3 | 判斷是否需要從 Level 0 |
| 基本詞彙（漢字） | 4 | 判斷 A1 / A2 |
| 簡單句子閱讀 | 3 | 判斷 B1 |
| 對話聽力 | 3 | 判斷 B2 / C1 |
| 段落閱讀 | 2 | 判斷 C1 / C2 |

### 分級邏輯
```typescript
// src/lib/placement.ts
function calculatePlacementLevel(answers: Answer[]): Level {
  const score = calculateScore(answers);
  if (score < 20) return 'ZHUYIN';
  if (score < 35) return 'A1_BEGINNER';
  if (score < 55) return 'A2_BASIC';
  if (score < 70) return 'B1_INTERMEDIATE';
  if (score < 85) return 'B2_UPPER_INTER';
  if (score < 95) return 'C1_ADVANCED';
  return 'C2_PROFICIENT';
}
```
